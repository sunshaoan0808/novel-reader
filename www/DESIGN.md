## 字体

- 标题/书名/人名：Noto Serif SC（--serif），字重 600-700
- 正文/按钮/标签：系统黑体
- **自托管**：`www/fonts/` 下 4 个 woff2（600/700 × latin/common），
  `@font-face` + `font-display:swap`，按 `unicode-range` 切片，浏览器只下当前页
  用到的那片。**不引 Google Fonts 外链** —— App 可离线运行，内网/国内 CDN 不可达，
  外链还等于把每个用户的请求交给第三方。
- 只出 600/700 两档：--serif 只用于标题/书名/人名，正文黑体从不需要衬线体。
- `common` 片只含 GB2312 一级+二级字（6763 字，覆盖现代简体中文常用字）。
- GB2312 之外的生僻字回落到系统宋体，字形略变但不出豆腐块 —— 这是知情取舍，
  为全覆盖把 31KB 的 unicode-range 列表塞进 CSS 不值当。
- 标题与正文必须一眼分出层级：标题 ≥16px serif，正文 13-14px
- **豁免：聊天气泡正文 16px / line-height 24px。** 这是长文本阅读面，13-14px 在
  360px 宽屏上会逼出频繁换行，是错的取舍。此前文档写"正文 13-14px"而代码是 16px，
  以本文为准——改文档，不改气泡。
- **下限 12px。** 描述性文字（卡片说明、统计行、状态行、chips 计数）不得低于 12px；
  仅纯装饰性角标可到 11px。
- 全文字号经 `--fs` 统一缩放（1 / 1.15 / 1.3 三档，只缩文字不缩布局盒子）。
  写尺寸一律用 `calc(Npx * var(--fs))`，不写裸 px，也不用根元素 `zoom`。

## 圆角与阴影

- 卡片：16px (--r)
- 小元素：12px (--r-s)
- 徽章/角标：4px (--r-badge)，头像：14px (--r-avatar)
- 按钮/标签：999px 胶囊
- 阴影两档：--shadow（卡片）、--shadow-s（小元素），不自创

| token | 用途 | 几何（各主题恒定） |
|---|---|---|
| --shadow | 卡片、弹窗、遮罩面板等"浮起来"的整块表面 | `0 6px 24px` |
| --shadow-s | 气泡、按钮、chips、标签等小元素 | `0 2px 10px` |

投影方向恒为正下方，只有模糊半径随"整块/小元素"分两档。

**实际生效值由当前主题给出**（`www/rp/theme.js`，在 `<head>` 里就写进 `:root`，
早于 `style.css` 的声明级联）。下表是无头浏览器里 `getComputedStyle` 的实测值：

| 主题 | --shadow | --shadow-s |
|---|---|---|
| 墨夜（默认） | `0 6px 24px rgba(0,0,0,.45)` | `0 2px 10px rgba(0,0,0,.28)` |
| 松烟 | `0 6px 24px rgba(0,0,0,.5)` | `0 2px 10px rgba(0,0,0,.32)` |
| 绛霞 | `0 6px 24px rgba(0,0,0,.5)` | `0 2px 10px rgba(0,0,0,.32)` |

`style.css:63-64` 里那组 `rgba(10,8,5,.55/.35)` 是**主题脚本没跑时的兜底值**，
只有 JS 挂了才会露出来，别把它当生效值抄走。

输入框的 `inset 0 2px 6px rgba(0,0,0,.4)` 是内凹阴影，不属于这两档，单独写死。

## z-index 阶梯

压叠顺序只能从这张表里取，**禁止在业务代码里出现裸 `z-index: 999`**（P2-55）。

| token | 值 | 装什么 |
|---|---|---|
| --z-bg | 0 | 聊天壁纸等背景层 |
| --z-base | 1 | 常规内容：卡片、chatwrap、卡内命中层 |
| --z-float | 2 | 卡内浮层：命中层之上的 ops 按钮行 |
| --z-sticky | 10 | 页内吸附：搜索条 |
| --z-nav | 20 | 常驻导航：顶栏、底栏、底部操作条 |
| --z-sheet | 30 | 浮层：聊天顶栏、悬浮球、回到底部 |
| --z-overlay | 40 | 遮罩 |
| --z-panel | 45 | 遮罩之上：右抽屉、消息 sheet、小助手窗 |
| --z-modal | 60 | 模态：确认框、新手引导、立绘 viewer |
| --z-toast | 90 | 瞬时提示：成就 toast、轻提示 |
| --z-lock | 120 | 全屏接管：PIN 锁 |

相邻两层至少隔 10，中间留出的空档就是给"同层内靠 DOM 顺序决胜"的元素用的。
层与层之间的东西不该靠 `z-index:auto` 碰运气，该给哪一档就给哪一档。

## 动效

- 同一页面只用一种 easing：`ease`
- 时长：120ms（按压）/ 300ms（显隐）
- 禁止 bounce/elastic
- 首屏不做无用户意图的动效

## 禁止清单

- 紫/蓝渐变（除非有明确理由）
- emoji 当图标（用图标集）
- 卡片套卡片
- 灰色文字压在彩色底上
- 一屏多个强调色
